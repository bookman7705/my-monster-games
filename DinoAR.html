Marker-based AR ready

Point at the marker

When camera access is enabled, move your device so the marker image fills the screen. The animated GLB model will lock onto the marker.

Print or display this image on another screen. MindAR tracks a binary .mind file generated from this PNG.
Note: use the MindAR tool to convert this PNG into `targets.mind` referenced in the script below.

Camera-free testing mode

This build is running with camera access intentionally disabled so you can test layout and the animated GLB model even on remote devices without a live camera.

When you are ready to test with a real camera, remove the NO_CAMERA_TEST_MODE flag and the // BEGIN temporary no‑camera preview block in the script at the bottom of this file.
